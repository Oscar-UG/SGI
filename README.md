# Sistema de Gestión y Reabastecimiento de Inventario

Objetivo del proyecto: Planificar y documentar una herramienta de control de inventario para una tienda, enfocada en
comparar el stock actual con el stock mínimo requerido para calcular de forma automatizada las necesidades de
reabastecimiento de productos.

Descripción del proyecto: Se trata de un sistema de gestión de inventario compuesto por un módulo de ingreso y validación de
datos, una estructura centralizada para almacenar información de los artículos, un algoritmo lógico de cálculo para saber 
qué cantidad exacta pedir a los proveedores y la emisión de reportes detallados para que el personal de bodega y los
administradores optimicen las compras y eviten desabastecimientos.
