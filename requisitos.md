## 4. Requisitos del Sistema (Requisitos Funcionales)

El sistema deberá cumplir con los siguientes requisitos funcionales:

1. **Solicitud del stock actual:** El sistema debe solicitar el stock actual de los artículos definidos:
   - Teclados.
   - Mouse.
   - Monitores.
   - Cargadores.
   - Audífonos.

2. **Validación de datos:** El sistema debe validar que los datos ingresados sean valores numéricos, enteros y positivos.

3. **Comparación de inventario:** El sistema debe comparar el stock actual de cada producto frente al stock mínimo preestablecido.

4. **Cálculo de cantidades:** El sistema debe calcular la cantidad exacta de unidades que se deben pedir únicamente cuando el stock actual sea inferior al stock mínimo establecido.

5. **Generación de reporte:** El sistema debe emitir un reporte final detallado y legible que presente los resultados del análisis de inventario.
